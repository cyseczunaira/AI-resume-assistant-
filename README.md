# 🤖 AI Resume Assistant

An AI-powered resume assistant that helps users create and improve their resumes using artificial intelligence.

## 🚀 Features

- Create a professional resume with AI assistance
- Generate resume content based on user information
- Improve and refine existing resume sections
- Generate professional descriptions for skills and experience
- Helps users organize their resume content
- Simple and beginner-friendly interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- Large Language Model (LLM)
- Google Colab

## 🧠 How It Works

1. The user provides their personal and professional information.
2. The application processes the provided information.
3. The information is sent to the AI model through the Groq API.
4. The AI generates professional resume content.
5. The generated content is displayed to the user.
6. The user can use the generated content in their resume.

## 📋 Resume Sections

The application can assist with sections such as:

- Professional Summary
- Education
- Technical Skills
- Soft Skills
- Work Experience
- Projects
- Certifications
- Achievements

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/cyseczunaira/AI-resume-assistant-.git
```

Go into the project folder:

```bash
cd AI-resume-assistant-
```

Install the required Python packages:

```bash
pip install -r requirements.txt
```

## 🔑 API Key

The application requires a Groq API key.

Set your API key as an environment variable:

```python
import os

os.environ["GROQ_API_KEY"] = "YOUR_API_KEY"
```

**Never upload your real API key to GitHub.**

## ▶️ Run the Application

Start the Streamlit application:

```bash
streamlit run app.py
```

The application will open in your browser.
